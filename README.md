# Anime Requester

A responsive and accessible web application that allows users to search for anime by title, ID, or ranking using the **Anime Requester API** via RapidAPI. Developed by **Les 3 Sinjes**.

🚀 **Live Demo:** [View on GitHub Pages](https://le-saint-basilic.github.io/AnimeRequester/html/key.html)

---

## Features

- 🔍 **Multiple Search Types:** Search for anime effortlessly by title, unique identifier, or global ranking.
- 🔑 **API Key Authentication:** Secure your requests by inputting your personal RapidAPI key before querying the database.
- 🌙 **Dark Mode Support:** Toggle seamlessly between light and dark themes for comfortable night-time browsing.
- ♿ **Accessibility (a11y) First:** Fully optimized with semantic landmarks, screen-reader-friendly attributes (`aria-*`), and custom keyboard navigation support.

---

## Getting Started

Because this application relies on the Anime Requester API on RapidAPI, you will need your own API key to execute requests.

### Prerequisites

- A free or paid account on [RapidAPI](https://rapidapi.com/).
- Subscribed to the **Anime Requester API** to obtain your personal API key.
